# Hey, I'm Gerson Rocha! 👋

**Senior Mobile Engineer & Tech Lead** · React Native · Expo · TypeScript · Rio de Janeiro, Brazil 🇧🇷

I've spent 5+ years building and shipping production apps for **iOS and Android** with React Native. I usually own a product from start to finish: requirements, system design, UI in Figma, implementation, CI/CD and publishing on the App Store and Google Play.

The apps I maintain today run on **140k+ active devices**.

### 📊 Highlights

- 📱 **140k+ active devices** across the apps I maintain, with tens of thousands of monthly active users
- 🏗️ **25+ white-label apps** running from a single monorepo (Yarn Workspaces + shared packages), where each app is only a brand layer on shared code
- 💸 Built fintech-style flows from zero (balance dashboard, withdrawals, receivables anticipation), with **15k+ withdrawals processed**
- 💬 Real-time chat with voice messages and optimistic updates: **800k+ messages exchanged**
- 🚢 **15+ releases in 8 months** using EAS Build/Submit, OTA updates with fingerprint-based runtime versioning, GitHub Actions and Fastlane
- ✅ **40+ Maestro E2E tests** covering critical flows, plus Jest and Detox
- 👥 Led a team of up to **6 developers**: RFCs, coding standards, code review and pair programming

### 🌱 Open source

Contributions merged into the Expo ecosystem:

- **[expo/expo#51370](https://github.com/expo/expo/pull/51370)** · `expo-notifications`: fixed an iOS `EXC_BAD_ACCESS` crash caused by concurrent access to pending notification handler tasks, traced from a production crash report
- **[expo/orbit#343](https://github.com/expo/orbit/pull/343)** · Orbit: added support for **DeviceHub.app**, the Xcode 27 replacement for `Simulator.app`, restoring simulator launch and management on the new Xcode

### 🔭 What I work with

- **Native features:** iOS Live Activities, widgets, Apple Health, Health Connect, biometric auth, push notifications, deep linking
- **Architecture:** offline-first apps, design systems, domain-driven structure with Expo Router
- **Backend:** Node.js, Express, PostgreSQL, Prisma, Socket.io, Redis
- **UX:** Apple Human Interface Guidelines, Material Design 3, accessibility (font scaling, reduce motion), i18n (PT/EN/ES)
