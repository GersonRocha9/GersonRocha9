# Hey, I'm Gerson Rocha! 👋

With **5 years of experience** in software development, I specialize in building **high-quality mobile applications** with **React Native** for both iOS and Android.  
I have contributed to the **entire app lifecycle** — from architecture design, RFCs, and design system implementation to CI/CD automation, testing, and publishing on the App Store and Google Play.

- 🚀 End-to-end delivery of multiple apps published on both stores, reaching thousands of active users.  
- ⚙️ Expertise in **CI/CD pipelines** using GitHub Actions, Fastlane, and EAS, ensuring automated builds and fast release cycles.  
- ✅ Strong background in **end-to-end testing** with Maestro, Detox, and Jest, increasing release confidence and reducing production issues.  
- 📱 Hands-on experience with **offline-first architectures**, ensuring reliability and scalability even in distributed environments.  
- 🛠️ Proven track record designing and maintaining **scalable backends** with Node.js, TypeScript, and PostgreSQL to support demanding mobile solutions.  

I am passionate about creating **digital products** that are not only technically robust but also deliver **meaningful user experiences**.  
Always exploring new technologies, I aim to push mobile development forward with **performance, scalability, and usability at scale**.
